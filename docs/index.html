Engineering Highlights

Built for stability, safety, and seamless day-to-day spoofing.

Mach-O Swizzling & CLLocation Injection

Injected dynamically into iOS IPAs via LC_LOAD_DYLIB. Hooks both asynchronous CLLocationManagerDelegate callbacks and synchronous [CLLocationManager location] queries with zero memory leaks.

Retained Static Cells

Prevents view re-parenting and keyboard focus loss when typing negative coordinates or decimal points.

Apple SF Symbol Badges

Native icon badges styled after iOS Settings with continuous corner squircle curves and high-contrast iconography.

Zero Gesture Conflicts

3-finger 0.8s activation gesture automatically pauses when the map sheet is presented, letting you pinch, pan, and zoom without accidental triggers.

Continuous Auto Updates

GitHub Actions CI automatically compiles arm64 Mach-O binaries on macOS and regenerates the AltStore repository JSON on every release.

quickstart.sh
# 1. Download compiled LocationSpoofer.dylib (v1.1.1)
gh release download v1.1.1 --repo getsentrix/LSpoof --pattern "*.dylib"

# 2. Or download via direct curl:
curl -LO https://github.com/getsentrix/LSpoof/releases/download/v1.1.1/LocationSpoofer.dylib

# 3. Inject into target IPA using Azule or Sideloadly
azule -i TargetApp.ipa -o SpoofedApp.ipa -f LocationSpoofer.dylib
